PCMode simple
=============

Use only these most of the time:

01 Normal
- Full performance PC mode. No CPU/GPU low-power limits.

02 Bureautique Chill
- Quieter desktop mode under Normal.
- Keeps screens on and keeps apps running.
- CPU/GPU are limited enough to avoid fan bursts, but still usable for heavy browsing and remote work.

03 Perf Gaming
- Gaming/performance mode.

04 Mode Nuit
- Quiet low-power mode.
- Keeps the PC awake for Minecraft/Parsec.
- Uses Windows display sleep so local mouse/keyboard can wake screens normally.
- DDC monitor sleep is disabled because two screens do not wake reliably from it on this setup.

If something breaks:
- Open "Advanced - secours".
- Run "99 Rollback Remote Setup.bat".
